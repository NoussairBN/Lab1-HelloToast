## Lab 1 : HelloToast

Ce projet est la réalisation du **Lab 1 - Programmation Mobile (Android)**. 
Afin d'aller plus loin que le simple exercice de base, l'interface et la logique ont été personnalisées autour d'un thème de cybersécurité .

##  Objectifs du Lab réalisés
- Création d'une interface utilisateur en **XML** (utilisation de `LinearLayout`).
- Liaison des composants visuels avec le code **Java** (`findViewById`).
- Gestion des événements de clics (`setOnClickListener`).
- Modification dynamique du texte à l'écran.
- Affichage de notifications temporaires (`Toast`).

## Fonctionnalités personnalisées
1. **Simulation d'attaque SSH (Compteur) :** Un bouton permet d'incrémenter le nombre de tentatives de brute-force bloquées, mettant à jour le `TextView` central instantanément.
2. **Analyse Réseau (Toast) :** Un bouton déclenche un `Toast` confirmant que le réseau est sécurisé.
3. **Design Thématique :** Interface mode sombre ("Dark Mode") avec code couleur type terminal (Noir/Vert fluo).
